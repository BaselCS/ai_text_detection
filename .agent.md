# Implementation details
1. **Experiment Setup**:
   - Always confirm `random_state=999` and `test_size=0.2`.
   - Ensure `train_test_split` is applied consistently across all notebooks.

2. **Metric Generation**:
   - Use `classification_report` to get per-class precision, recall, and F1.
   - For 7-class tasks, ensure all class names are correctly mapped for the report.

3. **Plotting & Saving**:
   - **File Naming & Organization**: Use the specific standard IDs for tables (`T1.csv`-`T8.csv`) and figures (`F1.png`-`F13.png`).
   - **Directory Structure**: 
     - Save CSVs to `results/tables/`.
     - Save heavy-res PNGs to `results/figures/` (300 DPI).
     - Save models with metadata to `results/models/`.
     - Save hyperparameter logs to `results/logs/`.
   - **Complexity**: Ensure models include metadata tags: seed (999), 80/20 split, and feature lists.

4. **Code Reference**:
   - Refer to `Evaluation/evaluation_utils.ipynb` for the standardized `evaluate_model` implementation.

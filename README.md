# AI Text Detection Project

Welcome to the AI Text Detection project! This repository contains the code and experiments for classifying text as either **human-written or AI-generated** (Binary task), as well as attributing AI-generated text to **specific language models** (Multi-class task).

Our methodology evaluates the effectiveness of two primary feature configurations:
1. **Features Only:** Using traditional stylometric and linguistic features.
2. **Features + BERT:** Combining stylometric features with deep contextual representations extracted from BERT.

## Project Structure

- `data/processed/`: Contains the preprocessed CSV datasets (main articles, cross-domain datasets, and adversarial attack datasets like misspelled/paraphrased text).
- `results/`: Contains the automated outputs generated by the scripts.
  - `models/`: Saved XGBoost models, scalers, and feature metadata (`.joblib` and `.json` files).
  - `tables/`: Generated CSV files containing statistical significance metrics, per-class F1 scores, and performance under domain shifts/attacks.
  - `figures/`: Generated visual plots (e.g., PCA dimensionality reduction).
- `Main.ipynb`: The main Jupyter Notebook where the core models are trained, evaluated, and where the primary results/figures are generated.
- `external_models.ipynb`: Additional notebook for external model validation.
- `case_studies.py`: A Python file that shows the model's performance on paraphrased text.

## Reproducing Results

To run the primary training pipeline and reproduce the core figures/tables:
1. Open `Main.ipynb` in your preferred Jupyter environment (VS Code, JupyterLab, etc.).
2. Run the cells sequentially. The notebook will automatically train the XGBoost models (both Binary and Multi-class), evaluate them on the test partitions, and output the results directly to the `results/` folder.


## Notes on Methodology
- **Reproducibility:** A fixed global seed (`SEED = 999`) is strictly used for train/test splits to mathematically guarantee the identical partitions across all experiments. 
- **Adversarial Resilience:** The notebooks include sections dedicated to testing the models against translation, paraphrasing, and stochastic misspelling attacks to evaluate real-world robustness.
